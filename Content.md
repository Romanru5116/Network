gRPC (gRPC Remote Procedure Call) — это высокопроизводительный фреймворк от Google для обмена данными между микросервисами. В отличие от привычного REST API, где приложения обмениваются текстовыми JSON-документами, gRPC позволяет одному сервису вызывать функцию на удалённом сервере так, будто она находится локально, используя быстрый бинарный протокол
Как устроен и работает gRPCЯзык контрактов (Protobuf): Вместо того чтобы придумывать структуру запросов, разработчик описывает данные и будущие функции в .proto файле.Автогенерация кода: Специальный компилятор берет .proto файл и автоматически создает готовый код (клиентские и серверные библиотеки) на любом популярном языке программирования (Go, Python, Java, C++, C# и др.).Транспорт (HTTP/2): В качестве сетевого протокола используется HTTP/2. Это дает огромный прирост скорости за счет сжатия заголовков, мультиплексирования (множество запросов по одному TCP-соединению) и возможности двустороннего потока данных

Чтобы начать использовать gRPC, выполните следующие шаги:
1. Напишите контракт (.proto файл)gRPC использует Protocol Buffers (Protobuf) для строгого описания структуры данных и методов. Создайте файл с расширением .proto
2. Сгенерируйте код для вашего языка программированияИспользуя компилятор protoc и плагины для вашего языка (Go, Java, Python, C#, Node.js и др.), сгенерируйте клиентский и серверный код на основе .proto файла. Этот код возьмет на себя всю рутину по сетевому взаимодействию и сериализации.
3. Реализуйте сервер (Server)Вам нужно написать логику метода SayHello, который вы описали в контракте. Сервер будет слушать порт и обрабатывать входящие gRPC-запросы.
4.Реализуйте клиента (Client)Создайте клиентское приложение. Благодаря сгенерированному коду вы сможете вызывать удаленный метод на сервере точно так же, как обычную локальную функцию, передавая ей объект HelloRequest.
